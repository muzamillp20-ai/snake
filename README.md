## ✨ Features

### 🎯 Core Gameplay
- **Classic Snake mechanics** with modern polish
- **Wrap-around borders** — the snake passes through walls and appears on the other side
- **Self-collision detection** — touching yourself ends the game
- **Progressive difficulty** — speed increases with each level

### 🏆 41 Progressive Levels + Default Game
- **Level 1**: Beginner-friendly with no obstacles
- **Levels 4-41**: Gradually introduce obstacles, speed increases, and tighter spaces
- **Level 41**: The ULTIMATE challenge — dense maze, fastest speed
- Each level has unique board themes, obstacles, and target scores
- Level completion unlocks the next level
- Progress saved locally via localStorage

### 🎨 10 Themed Boards
Classic Green, Wooden, Neon Cyber, Dark Arcade, Nature Garden, Ice World, Fire Arena, Royal Gold, Space, and Celebration — each with unique visual styling.

### ⚡ Power-Ups
- **⚡ Speed Boost** — temporarily faster movement
- **🐌 Slow Motion** — temporarily slower movement
- **💰 Golden Food** — bonus points
- **🛡️ Shield** — absorbs one collision

## 🕹️ Controls

### Desktop
| Key | Action |
|-----|--------|
| ↑ / W | Move Up |
| ↓ / S | Move Down |
| ← / A | Move Left |
| → / D | Move Right |
| Space | Pause / Resume |

### Mobile
- Swipe on the game board to change direction
- Or use the on-screen directional buttons

## 📦 Deployment

This project uses **GitHub Actions** for automated CI/CD deployment to GitHub Pages.

### How it works:
1. Push to `main` branch triggers the workflow
2. Dependencies are installed
3. Production build is created
4. Build artifacts are uploaded
5. GitHub Pages deploys the site automatically
