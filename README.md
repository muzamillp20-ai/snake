# 🐍 Mahira Mansha Snake Crash

A personalized snake game dedicated to Mahira Mansha, featuring MUZAMIL BHAIYA as the champion snake!

## 🎮 Play Now

**[Play the game here!](https://muzamillp20-ai.github.io/snake/)**

## Features

- 41 progressive levels + default game
- 10 unlockable snake skins
- 10 themed boards
- Power-ups (speed, slow, golden, shield)
- Wrap-around borders
- Mobile touch controls
- Sound effects
- Victory celebration: "MAHIRA, WINNER! BHAIYAA PROUD OF YOU! 🏆"

## Controls

- Arrow Keys / WASD to move
- SPACE to pause
- Mobile: Swipe or use on-screen buttons

## Development

```bash
npm install
npm run dev
npm run build
```

Built with React, TypeScript, Vite, and Tailwind CSS.
